# Feature: whisper

## Brief

Prints its text argument in lower case. Someone runs `bash scripts/whisper.sh "<text>"`
from the repo root. No screens, no network, no stored data.

## Rules

AC-1  When run with `HELLO`, the command prints exactly `hello` and exits with code 0.
