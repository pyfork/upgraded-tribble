# Slice S-002: When someone runs `bash scripts/slug.sh` without exactly one title that has an ASCII letter or digit, they see an error and a non-zero exit.

Feature: [brief](brief.md)
Slice: 2 of slug

## Outcome
When someone runs `bash scripts/slug.sh` without exactly one title that has
an ASCII letter or digit, they see why on standard error, nothing on standard
output, and a non-zero exit, instead of an empty slug.

## Rules

AC-6  Given no argument, or more than one,
      when someone runs `bash scripts/slug.sh`,
      then it prints nothing on standard output and exits 2.

AC-7  Given exactly one title with no ASCII letter or digit (`!!!`, `""`,
      `日本語`),
      when someone runs the command with it,
      then it prints nothing on standard output and exits 1.
